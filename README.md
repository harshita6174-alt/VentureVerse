# VentureVerse 2026 — Ideas into Action

VentureVerse 2026 is a fictional event landing page created for the EDC JSS University first-year applicant task.

## About the Event

VentureVerse 2026 is a student-focused entrepreneurship event designed to help students explore how early ideas can be developed into ventures.

The event includes startup learning sessions, founder stories, an idea sprint, pitching basics and networking opportunities.

## Features

- Responsive single-page layout
- Navigation links with smooth scrolling
- Event hero section with date, time and venue
- About and event highlights section
- Event schedule
- Fictional speaker profiles
- Registration call-to-action
- Interactive registration button using JavaScript
- Mobile-friendly design
- Hover effects for interactive elements

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — structure and content of the webpage
- `style.css` — styling and responsive design
- `script.js` — registration button interaction
- `README.md` — project information

## JavaScript Feature

The registration button uses a simple JavaScript event listener. When the user clicks the button, a registration information message is displayed.
